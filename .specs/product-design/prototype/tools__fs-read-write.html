参数 schema（JSON · 提交时校验） · 注册时同源字段

与下方「参数 schema（8）」表同源（此处改一处，表随之重解析）；校验未过会在字段旁页内显错、不落库。示例失败态：删掉 "required":true 保存 → 提示「path 必须 required」。

权限标签（chips 增删） · 注册时同源字段

read ×write ×project:write ×+ 添加标签

缺权限时调用返回 404 而非 403（避免用状态码探测资源存在性）；权限收紧即时生效，放宽需 admin 复核。

达软限即告警并在 run 内提示收敛。

达硬限直接截断该次调用并记 exec_fail 告警；硬限必须 ≥ 软限，否则字段旁显错。

安全闸门（三件套） · 注册时同源字段

前置闸门：入参校验。收紧即时生效（含 queued run），放宽需 admin 复核。

后置闸门：出参复核。关掉会让「写成功但内容不符」不可见，默认必开。

三档互斥单选：none 原样透传（仅隔离域内允许）· sanitize 当前值 · strict 只放行白名单类型并剥除二进制。

与产物区备份策略同源；改小会立即淘汰超出的历史快照。

自动保存 · 已存 16:40:12 三态：保存中 → 已存 / 失败（字段旁页内显错，不落库） · 保存只改期望态，在途 run 用旧配置
