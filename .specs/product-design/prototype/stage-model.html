状态-行为锚 · multica 完整清单 7 内置态 × 4 类别 事实校正 · 2026-10-23

上方目录表用 4 个生命周期类别（unstarted / started / done / closed，即原页所称「4 语义锚」）给阶段定位；任务侧的状态是挂在同一套类别下的 7 个内置 key。本轮校正的是一条容易记反的规矩：行为不挂在类别上，只挂在这 7 个固定 key 上。把某个阶段 / 状态归进一个类别，只决定它在看板上的位置与进度分母，不带来任何行为。

类别（建后不可改）内置状态 key（7 个）挂在该 key 上的内置行为（4 个，一 key 一个）自定义态归进同一类别会得到什么
unstarted · 还没动 —— 内置 2 态
unstartedbacklog 唯一停车态停车：把任务指派给 Agent 不建 run——挂在 backlog 上等，改到可跑态才开工只继承「未开始」的位置与进度口径；不停车（停车 = 状态标识，不是类别属性）
unstartedtodo无内置行为指派即建 run 入队（与 backlog 的唯一区别就在这里）
started · 正在做 —— 内置 3 态
startedin_progress失败回收：该态上的 run 失败 → 状态回 todo，不留在「进行中」装忙不继承失败回收：自定义 Started 态失败后停在原地等人处置
startedin_review结束自动化运行：进入该态 → 该任务在跑的自动化 run 收尾，不再续跑（评审中不该还有机器在改）不继承：进入自定义 Started 态不是命令 Agent 收工
startedblocked失败处理：run 失败的落点之一（转受阻 + 升收件箱等人 · 受阻理由留痕）不继承：进入自定义 Started 态不是命令 Agent 判败
done · 完成 —— 内置 1 态
donedone终态；在 done 上指派 Agent 同样立刻开跑——停车只认 backlog 这一个 key继承终态与进度分母；不继承「完成需证据」等按 key 配的门禁
closed · 关闭 —— 内置 1 态
closedcancelled 拼写：双 l，不是 canceled终态；在其上指派也会立刻开跑（真要停下靠归档与权限，不靠态）只继承生命周期类别，四个内置行为一个都拿不到

四枚按钮只把清单里最反直觉的四条事实做成可点口径，不落库；done 的证据门与状态在看板上的实际渲染见 任务看板 / 标 done，本页不重复。

五条配套边界（都是行为不继承这条主线的推论）：① 自定义 unstarted 不停车——backlog 是唯一停车态，停车是状态标识不是类别属性；同理 done / cancelled 上指派也会立刻开跑。② 自定义状态只继承生命周期类别，不继承那四个内置行为——「进入自定义 Started 态」不是命令 Agent 开工 / 收工 / 判败。③ 看板 · 列表 · 泳道的分栏用具体状态，不按类别合并——Code Review 与 QA 是两个自定义态就各占一列；把它们并进「Started」一列，等于把团队赖以协作的评审可视化直接吃掉。④ 类别建后不可改——改类别会把该态下全量历史任务静默挪到另一条生命周期轨道（进度分母 · 终态判定 · 收件箱自愈归档条件一起跟着改写），无提示、可回滚成本极高。⑤ 归档不退删除：归档是软撤销（archived_at + 操作者，可恢复），不是删除；自定义态归档前必须先迁空，否则 409 issue_status_in_use 并回 issue_count（还有多少任务压在上面），由人先迁再归档。

triage 注（别把两件事混成一件）：受理门 triage 是 AgentFlow 自研的正交轴，multica 全文无此态——上面 7 个内置态与 4 类别都在 status 这一根轴上，答「到哪一步」；triage 独立答「这算不算活（要不要自动派执行者）」，只拦自动推导执行者的运行，放行人点名派发。故本页清单不含 triage，看板列也不因它增列（消费面见 board.html status×triage 正交表）。

「不绑定任何开发流程」的落地检验：当这张表可以被改成一个 5 阶段或 12 阶段的模型、且不需要改任何代码时，§1.4 的这条边界才算成立。当前不成立。

保存动作的现状（必须写明）：「保存」走的是 PUT /api/admin/workflow，语义为整包盲覆盖——请求体就是新的 workflow.json 全文，服务端不比对版本，谁最后点保存谁吃掉前面所有人的改动。本表单打开后拿不到 ETag，多人（或 Agent）同时编辑不会有任何提示。P2-5 第一批（ETag/If-Match→412）落地后，本页保存遇到冲突应改为 412 + 冲突抽屉，而不是当前的静默覆盖。
