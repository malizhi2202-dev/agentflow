新阶段只继承生命周期，不继承停车 / 评审 / 失败恢复行为。必须先归入 4 个语义锚之一；归类建后不可改。

id      [2b-perf-baseline   ]   ← 建议 <seq><字母后缀>，避免撞历史 ID
name    [性能基线            ]
anchor  (*) unstarted   ( ) started   ( ) done   ( ) closed      ← 必选
file    [PERF.md          ]  required [ ]
gate    [无 ▾]   prompt [prompts/2b-perf.md ▾]
seq     [3 ]  （插到 2a-ui-design 之后，不影响既有判定链）

4 语义锚选择

锚含义当前阶段数新阶段放进去会得到什么
unstarted还没动5看板「未开始」列 + 进度缺口计入
started正在做3「进行中」列 · 不会自动启动 Agent
done完成（需证据）1终态 · 触发收件箱自愈归档
closed关闭（重复/作废）0终态 · 不计入进度分母

落地检验：把这张表改成 5 阶段或 12 阶段模型且不改任何代码，§1.4「不绑定任何开发流程」才算成立。当前不成立（配置面尚未接上，后端仍有 6 处阶段字面量）。

本页由 stage-model.html 的 dr-new 抽屉升格而来：新增阶段是带校验的可编辑表单（6 个字段 + 锚选择表），不能塞在浮层里。
