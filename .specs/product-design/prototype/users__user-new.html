同步生成预览 只读 · 不可取消勾选

创建时将同步生成：钱七 · 个人 Agent 与用户 1:1

owner
钱七（随新建账号）· Agent 归属即用户归属
可见性
private（默认仅本人可见可运行 · 不随用户权限授予而扩大）
绑定运行时
默认 · 其选用（用户后续可自换；未选前不可运行）
域 / 命名
域=未分类 · 命名规则「<显示名> · 个人」（如既有用户 → 「李四 · 个人」；已有专名如「运维哨兵」则保留直链）

每创建一个用户就创建一个关联 Agent，一一对应，代替这个人做事。归档用户 → 其个人 Agent 同步置为不可运行；删除用户不自动删 Agent（需二次确认处置）。以上为原型演示口径。

本页由 users.html 顶栏「+ 新建用户」的弹层升格而来：5 个字段 + 两组勾选 + 同步生成预览卡（只读）+ 保存钮，已超出 pop 只放选择器的边界（纪律 D）。「初始口令」字段按 P0-2 以划除态呈现，不再产生 123456。个人 Agent 为系统代建项：不出现在权限点勾选里，创建后在 users.html「个人 Agent」列与 agents.html 列表（chip「user-level · 个人 Agent」）可见。

可点区演示：创建 → toast（已创建用户 + 1:1 个人 Agent · 演示）后回用户列表 · 取消 → 回用户列表 · 「Agent 列表」相关页 pill → agents.html。
