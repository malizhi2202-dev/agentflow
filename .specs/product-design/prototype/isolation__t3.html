无 KVM 是这一档在单机上的关键卖点（systrap 默认平台，无需内核改动、不需要 /dev/kvm）——所以 runsc 一装就能把 min_tier=T3 的不可信域跑起来。

形态与契约

形态
Docker + gVisor 运行时（--runtime=runsc）
隔离强度 / 失效面
中高：应用内核接管 syscall → 内核攻击面大幅缩小；失效面转到 gVisor 自身 · syscall 密集任务性能打折
冷启动
~1s（与 T2 同级，大头仍在 Docker）
KVM 依赖
无需（systrap 默认平台 · ptrace 平台已停支）
本机探测
docker info Runtimes 无 runsc → 不可选
性能特征（如实说）
CPU 密集≈零损失 · syscall/文件路径密集打折（官方给定性描述与 CSV，无固定倍数）
切换成本
一键：装 runsc → 复探 → 域策略 min_tier 提到 T3
契约不变项
ttl / shutdownPolicy / egress / 短票 —— 与档位正交，升档不影响这些
开放条件
探测到 runsc 即转「可开放」（探测开放铁律 ①，不提前宣称）
不可达时的行为
拒绝执行并三处标 isolation:none，禁止静默回退 T0/T2
