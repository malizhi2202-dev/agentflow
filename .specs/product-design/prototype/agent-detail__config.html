8 · MCP 服务绑定 三态 · 已保存不回显

保存后该 Agent 的 mcp_config = null：运行时不注入任何 MCP，技能自带的文件 / 抓取能力会退化（历史 run 的 MCP 调用记录保持快照不变）。MCP 服务本身不删——它们仍被另 2 个 Agent 绑定。

预置为「当前生效配置」的演示重建值——真实系统不回显已保存 JSON（含 token），只有本区处于「整体替换」时才让你重新粘贴全量。

transport：stdio = 平台随 run 拉起子进程（配置含 command / args / env）· http = 连远端服务（配置含 url / header，header 里可能带 token）。两者配置体都按敏感值规则处理：存储加密、界面 ***、日志脱敏、专用端点写入。

运行时联动：所选 dsh 支持平台托管 MCP，故本区可见；换成 copilot（不支持）时本区整体隐藏并注记「该运行时不支持平台托管 MCP」，已存配置保留不动。
