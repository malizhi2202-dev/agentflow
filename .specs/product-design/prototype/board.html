状态与行为解耦（沿用 Multica 的两条硬规矩 + 内置锚行为清单）：① 状态标签只表达语义，不授予行为；② 进入「进行中」不是命令 Agent 开工——启动必须由显式的运行请求或触发规则产生。③ 行为只挂在固定 key 的内置锚上（四条，逐条对号）：backlog = 唯一停车态（停在 backlog 永不出队、不派生执行）；in_progress = 失败回收（本态内 run 失败按回收路径处理，升收件箱不静默吞）；in_review = 结束自动化运行（进入评审即停自动化推进，done 留人）；blocked = 失败处理（受阻/失败挂 wait_reason，唤醒只由人解除）。④ 自定义状态只继承生命周期位置，不继承以上任何行为——给自定义状态挂行为需独立裁定，不会自动获得。
