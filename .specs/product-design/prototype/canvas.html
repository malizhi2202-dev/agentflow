校验提示：旧版审查 Agent 引用的工具已被禁用，执行时将失败。

YAML（与画布双向同步）

name: 审查流水线
version: 3
nodes:
  - id: review      { agent: 审查 Agent · 标准, model: gpt-4o }
  - id: frontend    { agent: 前端 Agent,       model: claude-sonnet }
  - id: sync        { agent: 数据同步 Agent,   model: deepseek-v3 }
  - id: merge       { agent: 汇总 Agent,       model: gpt-4o-mini }
edges:
  - { from: review, to: frontend, type: fan-out, retry: 3, timeout: 120s, max_tokens: 32000 }
  - { from: review, to: sync,     type: fan-out, retry: 3, timeout: 180s }
  - { from: frontend, to: merge,  type: fan-in }
  - { from: sync,     to: merge,  type: fan-in }
  - { from: review,   to: legacy, type: retry-fallback, on_exhausted: dead-letter }
