演示数据工具库「新建」升格页：Plugin / Skill / MCP 三类分型表单，语义不同、字段不同、不共用一张表单（业界共识）。顶部 tabs 为静态展示，各 tab 点击即说明语义；四种导入方式只决定初始值来源，不改变表单结构。

Plugin Skill MCP
手工 从本地导入 从 URL 导入 从运行时拷贝

三类语义不混：Plugin = 平台内置代码实现；Skill = 描述性登记由 Agent 按提示词执行；MCP = 外部服务 tools/list 运行时发现。四种导入方式对三类通用，但表单字段分型——导入只决定初始值来源。

注册即生成详情页；之后所有字段在详情页同源可编辑（同一份配置，两种入口）。本页只是首次登记入口——创建后逐字段编辑落到详情区的「配置（与注册表单同源）」：① Plugin → tools__fs-read-write.html · ② Skill → tools__code-review-skill.html / tools__skill-browser.html · ③ MCP → tools__mcp-filesystem.html / tools__mcp-fetch.html。每页头部「✎ 编辑」进入编辑态、底部 sticky 保存条落库；无 tool:edit 权限者整区为 🔒 Lock read-only（§6.0 ①）。

② Skill 表单 Skill

名称   [ 代码审查 skill                    ]
描述   [ 按规范检查变更并产出 REVIEW.md      ]

SKILL.md Markdown 编辑器（多行）

# 代码审查
## 何时适用
- 变更需要人工审查时
## 开始前检查
- 确认 diff 范围与规范版本
## 步骤
1. 读取变更 2. 逐条对照规范
## 结果形式
- REVIEW.md
## 何时停下问人
- 规范冲突 / 证据不足时

支持文件（随 SKILL.md 一并投喂）

目录文件说明
references/style-guide.md编码规范（审查依据）
templates/REVIEW.md.tpl审查报告模板
scripts/lint.sh辅助校验脚本

支持文件清单随 SKILL.md 一并登记并投喂；导入方式（本地 / URL / 运行时拷贝）会把这些文件打包解包后回填此处。

MCP 工具条目不渲染成 Skill（纵向层红线）；密钥仅存密文，运行时经 ${secret:NAME} 注入，不落明文。注：transport 枚举现按 STDIO / Streamable HTTP 渲染（上方表单里的「SSE」为旧称），详情页配置区同名同序；本表单的每个字段在创建后都在该服务详情页「配置（与注册表单同源）」区逐项可改。
