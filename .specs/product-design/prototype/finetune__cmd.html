下面的原文是给你复制去跑的：装不装、何时装由用户决定；平台侧只在「检测到 CLI 可用」后才把训练任务交给它（能力探测，不硬判版本号）。交付三形态齐了：可复制命令 / 可下载脚本 / 操作路径，三者都不产生执行。

① 安装 LLaMA-Factory（本机 · 用户自跑）

pip install "llamafactory[torch,metrics]==0.9.*"
llamafactory-cli version        # 平台探测这一条：能跑通即视为可用

⧉ 复制

② 数据集（本域脱敏导出 · 指纹入台账）

# data/dept_router_v5.jsonl（468 条 · 字段: state / question / options / label_scores）
# sha256 前缀 a91f… 写入数据台账，可回放「哪些会话被用过」

⧉ 复制

③ 训练（LoRA r16 · log-score 损失）

llamafactory-cli train \
  --stage sft --finetuning_type lora --lora_rank 16 \
  --lora_target o_proj,q_proj,k_proj,v_proj \
  --model_name_or_path Qwen/Qwen3.5-2B \
  --dataset dept_router_v5 --template qwen \
  --num_train_epochs 3 --learning_rate 1e-4 --cutoff_len 2048 \
  --per_device_train_batch_size 4 --gradient_accumulation_steps 8 \
  --output_dir .specs/small-model-decisions/artifacts/dept-router-v5-ft/adapter

⧉ 复制训练命令 ⧉ 复制 yaml 版

④ 三指标自测（过门槛才允许切产）

llamafactory-cli eval \
  --model_name_or_path Qwen/Qwen3.5-2B --adapter_name_or_path artifacts/dept-router-v5-ft/adapter \
  --task router_choice --metric accuracy,ece,agreement --baseline v1.2
# 门槛（服务端判定 · 域策略可审计项）：accuracy ≥80% 且 ECE ≤0.05

⧉ 复制 ⭳ 下载装机脚本 .sh
