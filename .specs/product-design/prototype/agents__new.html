7 · 能力 · 集成 IM 通道连接器 · 6 类通道

界分：IM 通道 = 对外消息出口；协作小队 = 站内 Agent 编组，互不混用——小队是执行层编组（leader + 成员池 · 可被指派），不在本区配置：协作小队 · 代码审查小队 →

连接后闭环：IM 消息 → 平台会话 → Agent run → 回复写回原聊天。一通道 × 一 Agent 仅一 bot（UNIQUE(workspace, agent, channel_type)），同 Agent 可并挂多平台。集成不是泛义「外部服务授权」：GitHub / CI 那类属 MCP 与工具库，IM 通道才是本区。

卡片五态：未启用（平台 configured 门）/ 不可用预览 / 未连接 / 已连接（bot 身份回显）/ 无权限只读降级。密钥三原则：写-only 不回显 · 改密钥=断开重连 · AES-256-GCM + 全局 DEK 落库。断开=软撤销（status=revoked 不物理删行）+ 必填原因。

10 · 设置 · 环境变量 值写-only · 保存后不回显

删除

已填 1 项 · 值仅 owner/admin 可解锁修改，读写均留审计（env:read 记账）；PATH / HOME 与平台保留变量不可覆盖；凭据一律放环境变量而非 CLI 参数。行级编辑用保留哨兵 **** 表示「保持原值不变」；env 只走专用端点整包保存（带 rev 乐观锁），常规更新请求体里带 env 一律 400。

11 · 设置 · CLI 参数 exec 数组 · 无 shell 展开

exec 数组逐项追加进 argv，无 shell 展开（$VAR / 引号 / 管道不解析）；禁放凭据——argv 可被同机进程 ps 看到，凭据走环境变量。详情页另有 launch 预览（拼好的 argv 原样可见）。

12 · 执行设置 并发 + 会话续跑 · 随运行时联动

默认 6 · 实际与机器 daemon 的全机上限（20）取小；负载率 = 当前并发 / 上限。

✓ 由运行时决定 所选 dsh 支持：平台存会话 id，下次 run 续跑；运行时够不到该会话时新建会话继续。（mcode 不支持，每次新会话）

本区两项随第 3 节运行时选择联动显隐；「续跑会话累计轮数超限后新建会话继续」的阈值在详情页「设置 · 通用」里调，创建页不给。

13 · 设置 · 闸门 = 详情页「设置 · 闸门」同一字段

闸门规则加在状态转换层（动作者 × 目标状态），不只写进提示词。收紧即时生效，放宽需 admin 复核。

归档 / 彻底删除、探活配置在创建完成后的详情页设置中（对应详情页「设置 · 危险区」「设置 · 探活」两子栏）：新建对象没有「在途任务 / 编排引用 / 能力组漂移」可查，删除前置检查与探活只有在 Agent 真实存在后才有意义，故创建页不设这两节。创建完成后入口：设置 · 探活删除前置检查（独立页）

复制语义：拷贝到新运行时时「模型 / thinking 档 / 服务档」清空需重选；环境变量值、MCP 配置与 IM 通道凭据从不复制（换实例=重新连接、重新在线验证）。
