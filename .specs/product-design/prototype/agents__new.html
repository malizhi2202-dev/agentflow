5 · 模型与运行时 平台不本地运行模型

运行时 = 外部 AI 编码 CLI 框架（DeepSeek Harness dsh / Codex CLI codex / Claude Code claude / Hermes hermes / Qwen Code qwen…），由机器上的 daemon 经「运行时发现」探测注册，run 一律调用这些 CLI。模型目录由所选运行时暴露（如 dsh --list-models 广告 · id 形如 provider/model），非平台内置。

仅可选机器 daemon 已探测为在线的运行时；离线项置灰——先在运行时发现页确认在线与已登录。

切换运行时后旧模型失效需重选；运行时离线时刷新得空列表，先确认在线与已登录。

仅 codex 类 CLI 有服务档；其余运行时忽略此项。

7 · 域归属 可空 · 不选=未分类

① 创建时域是可选字段：不选即 domain_id=NULL（外键 SET NULL），Agent 不隶属任何域。
② 管控面把无域 Agent 收进「未分类」虚拟分组，随时可「归入域」事后指定。
③ 域只是分组与共享记忆边界，非安全边界；自动路由按能力标签；删除域时其 Agent 回落未分类。

8 · 执行设置

默认 6 · 实际与机器 daemon 的全机上限（20）取小
删除

已填 1 项 · 值仅 owner/admin 可解锁修改，读写均留审计；PATH / HOME 与平台保留变量不可覆盖；凭据一律放环境变量而非 CLI 参数。

exec 数组逐项追加进 argv，无 shell 展开（$VAR / 引号 / 管道不解析）；禁放凭据——argv 可被同机进程 ps 看到，凭据走环境变量。

filesystem ✓ fetch postgres

所选 dsh 支持托管 MCP；换成 copilot 时本区隐藏并注记「该运行时不支持平台托管 MCP」。MCP 配置含 token，存储/显示规则同环境变量。

GitHub · issue 跟踪 ✓ CI ✓ Notion Slack

集成 = 外部服务（issue 跟踪 / GitHub、CI、Notion、Slack）的授权连接，凭据由平台代管、run 中供工具调用；与 MCP 的区别：MCP 是协议服务，集成是服务账号。

✓ 由运行时决定 所选 dsh 支持：平台存会话 id，下次 run 续跑；运行时够不到该会话时新建会话继续。（mcode 不支持，每次新会话）

9 · 安全闸门

闸门规则加在状态转换层（动作者 × 目标状态），不只写进提示词。

复制语义：拷贝到新运行时时「模型 / thinking 档 / 服务档」清空需重选；环境变量值与 MCP 配置从不复制。
