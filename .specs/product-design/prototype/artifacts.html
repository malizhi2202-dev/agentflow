# agent-domains — 需求文档

> 版本: 1.0
> 状态: draft
> 创建: 2026-07-06

## 概述

为 Agent 控制面板增加 **隔离域（Domain）** 功能，允许用户将
Agent 按域（如：开发域、测试域、生产域）分组管理。

## 功能需求

### FR1: 域 CRUD
- 创建域：name（必填）、owner_id（默认当前用户）
- 删除域：将域内所有 Agent 的 domain_id 置为 NULL（回归默认域）

### FR2: Agent 归属域
- Agent 表新增 `domain_id` 字段（可为 NULL）
- GET /api/agents?domain_id=X 按域过滤

## 验收条件

- [ ] 域 CRUD API 正常工作
- [ ] 删除域后 Agent 回归默认域
- [ ] TypeScript 无新增编译错误
▌

保存前自动备份：写入前先把当前版本复制到 backup/，保留最近 5 个版本；需要时可回滚。

路径安全：所有读写都经 config.get_specs_dir() 与提示词目录解析函数，不接受前端传入的绝对路径，因此不存在路径越界写入。
