开启 A 档 · AF_ENABLE_METRICS=true？

env 开关 = 对外面变化，按纪律二次确认。此页只读呈现生效值，确认结果是生成写入建议（供部署侧应用），本平台不热改自身进程环境。

  • 打开后 GET /metrics 对外可读：RED 指标 + 直读现表 Counter/Histogram（MySQL）
  • 暴露内容：域/能力名、运行计数、耗时直方图、token 汇总（不含会话原文与凭据）
  • 需配 excluded_handlers（健康检查与 /metrics 自身不打点）
  • 不改变 trace_spans 仍 0 行的事实——B 档此刻打开也无东西可导（前置 C10-0）
  • 撤销成本低：清 env 重启即下架（见「撤销已开的对外面」）
配置 B 档 · AF_OTLP_ENDPOINT？

这会把 span 推到外部采集器——一次跨网出面的动作，且当前前置未满足。

  • 前置未达：trace_spans 0 行 → 打开后导出为空，只会看到「管道通了没水」
  • 语义：OTel GenAI（invoke_agent / execute_tool / usage.*_tokens）· 全 Development 期不冻结对外契约，允许 agentflow.* 兜底
  • trace_id 为合成值 · 需在接入文档书面声明「非 W3C 原生」
  • egress：出口需加入白名单（§6.26 执行隔离页 · 新增即入审计）
  • 可选翻译层 OpenInference 只在接 Phoenix 时开

撤销已开启的对外面？

破坏性=对外部消费者破坏：一旦有 scrape 或采集器接上，下架会让对方的看板断流。当前状态：A/B 均未设、M0 未挂载 → 无外部消费方，撤销零影响。

  • 将下架：/metrics（若已开）· /api/watch（若已开）· /.well-known/agent-card.json（若已挂载）
  • 保留：历史指标与 change_log 记录（可计量数据走权威库，裁定⑦）
  • 重开需再次二次确认；对外承诺文档同步标注「已撤回」
