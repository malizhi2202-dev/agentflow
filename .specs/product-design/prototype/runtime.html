中断会话 rt-1-1783349487？

需 workflow:stop 权限。影响清单：

  • 进行中的 step 3 工具调用直接终止；已发出的外部副作用（已写入的文件）不回滚。
  • 下游 fan-in 等待数少 1，merge 节点可能永远等不齐 → 需同时中止整条 run r-128。
  • 已消耗 4,120 token 已入账（metrics_raw），不可撤销。
  • 会话在平台进程内执行：中断只结束本次调用，不重启 Agent 实例。
  • 必填原因，动作入审计 rt:interrupt。
原因: [审查范围写错，改为整条 run 重跑 ]
摘流该 Agent（停止派发新任务）？

摘流 = 从路由候选集中摘出，在途任务继续跑完；不杀进程、不清队列（调度队列同为进程内状态，重启即散）。影响：

  • 在途 1 个会话（rt-1-1783349487）继续执行至结束。
  • 新任务改由同能力组其他 Agent 承接；无可用副本则任务滞留队列并出 agent_dead 类告警。
  • 调和循环不会替被摘流的实例扩容回期望值（需先解除摘流）。
  • 必填原因，动作入审计 agent:drain。
原因: [准备换模型配置，先摘流避免打到半路改 ]
