断开 MCP 服务「fetch」连接？

当前已是「连接失败」态：断开 = 停止自动复探并转为「未连接」，已缓存的工具 schema 保留可查，引用它的 Agent 下次执行直接报错。必填原因。

原因: [端点迁移中，先断开避免 30s 复探持续打空 ]
禁用 MCP 服务「fetch」？

禁用全局生效且可逆：卡片保持可见（不隐藏），三处引用（数据同步对账草稿 · 数据同步 Agent · 前端 Agent 草稿节点）在下次执行时才失败。与「断开」的差别：禁用不再复探、也不受复探成功影响。必填原因入审计。

原因: [上游服务下线迁移，先停用避免复探打空 ]
