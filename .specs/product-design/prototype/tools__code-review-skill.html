指令内容（SKILL.md · Markdown · 多行） · 注册时同源字段

这一段就是进执行 prompt 的全部内容；导入方式（本地 / URL / 运行时拷贝）解包后回填同一份。

换内容保身份（2026-10-23 R8-9）：来源已钉住（上游仓库 / URL，登记件带 origin 字段）的技能，刷新只换正文与随附文件——库内 id 与全部 Agent 绑定保持不变，不必重绑；例外：runtime 拷贝复制即脱离，刷新不传导进拷贝件。导入同名 = 四态选择：fail overwrite rename skip，其中覆盖（overwrite）权限窄于编辑权限——覆盖归原注册人独占，一般编辑权不自动带覆盖，同一资源两条写路径权限不同是有意的。
