7 · 关联对象（多选）Agent / 工作流 / 知识库 / 会话 / 任务

☑ Agent ☑ 工作流 ☑ 知识库 ☐ 对话会话 ☐ 任务

关联语义：一 Agent 可属多项目，一项目可绑多 Agent（N:N 连接表）；工作流 1:N 快照；知识库 = 专属空间 1:1 + 只读关联 N:N；对话会话 / 任务 以 project_id 关联列挂靠。

创建仅写平台内登记（路径映射 · 成员分配 · 专属知识空间 · 关联台账），不在盘上创建目录；审计 project:register + space:auto_created（演示）。

字段裁撤说明（页脚）：曾有「开始日期 / 目标日期」两项，现已删除——项目无期限概念，节奏由里程碑 / 任务承载（任务见 board.html）。状态与优先级保留为单选 chips；Leader 从「成员或 Agent 二选一」改为「仅 Agent（用户级 Agent 优先）」，人只出现在成员与审批里。

可点区演示（独立表单页 · 纯静态）：名称 / 描述为两个独立输入框（描述 textarea）· 图标 = 9 个单选圆形 chip（跳过 + 8 emoji/字母 · 默认跳过）·「📁 选择目录…」→ toast + 路径 chip（✕ 可移除）· GitHub 输入框 +「⟱ 克隆并关联」→ 克隆 toast · 状态（未开始 / 进行中 / 已暂停 / 已完成）/ 优先级（低 / 中 / 高 / 紧急）/ 可见性 = 原生单选按钮组 chips（点 label 即切选中态 · 纯 CSS，chip 上不挂 toast 以免 preventDefault 吞掉选中）· 无开始 / 结束时间字段（理由在页脚）· Leader 单选（用户级 Agent 组 + 其他 Agent 组 · 归档项置灰）→ 选人 toast · 成员 5 行「类型（用户级 Agent / Agent / 用户）/ 对象 / 角色」下拉 + 逐行移除，「＋ 加一行」→ toast（可继续添加；创建者 owner 行与 Leader 行不可移除）· 第 6 区为创建流程 callout（项目 1:1 专属空间 + 关联已有知识库只读多选）与 L0-L3 总结写入卡（演示口径 · 参考腾讯记忆分层）· 空间「进入」深链 → knowledge.html#space-agentflow ·「提交创建」→ toast（已创建项目「agentflow」· 专属知识空间同步创建 · Leader：李工的个人 Agent）· 取消 / 顶部「← 返回」→ 项目列表　按 Esc 关闭浮层。
