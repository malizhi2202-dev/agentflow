# ① 头脑风暴 · S14 Agent 创建链路（第5轮 2026-09-23）

技法：**SCAMPER** + **逆向（问题反转）** + **类比迁移（K8s CRD / 应用商店）**。每条候选标「回应哪条事实」（F 编号见 `RECON.md` 本地真值节）。

|---|---|---|---|
| C1 | 创建改为**分步向导**（身份 → 人格 → 模型与凭据 → 能力装配 → 试运行），每步只问该步该知道的 | SCAMPER-调整（把 Detail 页调整为向导） | F-1 一个按钮直裸建、F-5 人格字段静默丢 |
