## 结论（推荐 1 主线 + 2 配套）

**主线：编排配置的「三权分离提案制」**——文献共识（APE 2211.01910 / OPRO 2309.03409 / AFlow ICLR25 Oral：优化器与被优化物分离）+ Magentic-One 证明「运行期动态规划」与「配置发布权」正交：
1. **提案生成权**（自动）：指标→提案引擎（①#1）。低成功节点/高成本边/备援不均→提案卡（调参/换备援/加撤边），预算显式限步限钱；AFlow 式搜索为远期档，搜索空间裁剪到声明式 YAML **禁触代码**（用户第 0 步裁定）。
2. **离线评估权**（自动但隔离）：影子重放历史任务（①#3）+ **冻结金标 metric 集 + 异源 judge**——Panickssery 2404.13076（fetch 实题「LLM Evaluators Recognize and Favor Their Own Generations」）实证自评偏袒，judge 必须异模型。
3. **发布权**（人）：零新门——提案过审→fork 画布草稿→diff 对账→Apply（原因自动填提案 id，①#6），复用既有版本链。

**配套 A：回归熔断**（①#7）：新版连续 N run 指标劣化→自动回滚上一版+审批单。配置态的 reconcile，回滚事务留账（S20#6 同条）。
**配套 B：提案限流与合并**（①#8）：每对象每周 ≤K、相似合并；细则归 S20 治理门。
**权重/阈值调优建议**（①#4）并入主线：备援权重与 0.60 的「建议值+置信+理由」由提案引擎产出，人从不直接改现值。
