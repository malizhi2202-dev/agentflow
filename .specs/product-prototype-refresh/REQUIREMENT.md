- **归属字段**（G1 🔴 · **四值枚举由 G2 🟫 收口，唯一口径，RESEARCH §2 与原型标注均以此为准**）：① `本项目已有`（须能指到 `pages/`/`routes/`/`components/`/`models/`/`services/`/`engine/` 锚点）；② `部分已有`（含"部分已有（半成品）"——有壳无芯，如 G6 `TraceViewer` 零挂载；**同样须指锚点，且必须点明缺的那半条腿**）；③ `缺失-竞品建议新增`；④ `缺失`（无任何竞品参照的自证缺口，如 G12）。①② 不得画成整条已交付，③④ 不得画成既有界面已具备的样子。

## 2. 用户故事

- **US-1**：作为**平台 owner**，我想有一份与代码自洽、可浏览器直开、覆盖全部 11 能力域与 32 个挂载页的产品原型，以便对外讲清「平台现在到底有什么」而不被过时 README 误导。
- **US-2**：作为**新接手的开发者**，我想在不启动前后端、不登录的情况下看到界面骨架（侧边栏 13 个一级入口 + 每域页面），以便一次读懂产品信息与导航结构。
- **US-3**：作为**产品决策者**，我想看到同类产品各自有、我们没有的能力，每条带来源与去向（融入原型 / 需代码议题 / 否决+理由），以便一次决定下一步投什么、不投什么。
- **US-4**：作为**评审者（6-review / S-align）**，我想抽查原型里任何一条能力陈述都能落到代码锚点或来源 URL，以便不被竞品宣传文案和"看着像引用"的句子污染事实源。
- **US-5**：作为**安全负责人**，我想让原型如实标注既有安全边界（本地开发默认口令、localhost + header 回落、密钥强度取决于 `ENCRYPTION_KEY`）且示例全合成、登录态用占位符，以便这份天生会被转发下载的文件不把演示边界当成已交付防护、也不泄露凭据。
- **US-6**：作为**下游执行者（2-design / 2a / 4-dev）**，我想拿到 v1 / v2 / out 三类都有内容的范围切分与逐条可验证的 AC，以便不越范围、不顺手改代码。
- **US-7**：作为**文档维护者**，我想让原型自带校准基线（commit + 日期 + 清单快照），以便将来能判定它自己是否又漂成了下一份过时稿。

### AC-3 · 零外部资源、零网络调用（供应链闸口 + out-1 的机器闸）
- **Given** 交付的原型 HTML
- **When** 在断网环境双击打开并跑加强版 grep；再人工搜 `http` 走查一遍
- **Then** 完整渲染；**无任何外部资源加载**（含协议相对 `//`、`srcset`/`poster`/`data-src`/`background` 属性、`url()` 远程、`<iframe|frame|embed|object|base>`、preload/prefetch/manifest/icon 类 `<link>`、`meta refresh`、SVG `<use href>`）**且无任何网络 API 调用**（`fetch(` / `XMLHttpRequest` / `sendBeacon` / `EventSource` / `WebSocket(` / 动态 `import(` / `importScripts(`）——后半组同时封住 out-1「不给原型接真实数据」（例：`fetch('http://<回环>:8000/api/…')` 一份稿即可满足旧 AC-3 与 AC-12，故必须闸）；**允许且必须保留 `<a href="https://…">` 来源引用**（R6.2 出处，删它才是违规；走查时余下的 http 只应出现在这类节点与内联 `<style>`/`<script>`、`data:` URI 中）

  - 命令双向可核（G2 🔴 已在样本上验，本阶段复跑一致）：对含协议相对样式表 / 远程 `url()` / tracking pixel / `<iframe>` / 内联 `fetch()` 的反例稿 → **5 命中**；对含 `<a href>` 来源引用 + 内联 style/script + `url(data:…)` + `<img src="data:image/svg+xml…">` 的合格稿 → **0 命中**。**旧命令对同一反例稿判 0 命中**，即本条存在的理由。
