## 1. 调性（继承 0.6 锁定，不重选）

**深色工程控制台（engineering console）**：高信息密度、克制配色、平直表面、语义色只用于状态。
产品本身就是夜间使用的控制台 → 沿用深色**属于既有设计系统**，不是"默认 dark mode 蹭潮流"（反模式里那条针对营销页）。

## 2. 色板与语义（只用既有 token，不新增）

| 用途 | token | 说明 |
|---|---|---|
| 页面底 | `--bg-main` | 主内容区 |
| 卡片/抽屉 | `--bg-card` / `--bg-panel` | 单层表面，**不做卡片套卡片** |
| 选中/悬停 | `--bg-selected` / `--bg-card-hover` | 列表选中态 |
| **唯一强调色** | `--blue`（+ `--blue-bg` / `--blue-border`） | 主按钮、当前 tab、焦点环 |
| 状态语义 | `--green` 运行中 / `--orange` 暂停或警告 / `--red` 归档或错误 / `--text-muted` 只读 | 仅状态，不做装饰 |
| 文字 | `--text` / `--text-secondary` / `--text-muted` | 三级 |
| 边线 | `--border` / `--border-strong` | 1px 分隔；**禁用彩色侧条** |
| 圆角 | `--r-sm`（卡片/输入）/ `--r-md`（抽屉） | 两级够用 |

> **两个强调色的处理**：反模式要求"一个声音"。本页只有 `--blue` 是装饰性强调；`--green/--orange/--red` 是**状态语义**且带文字标签（不单靠颜色传达），不构成第二个声音。

## 3. 字体与间距

- **字体**：沿用项目 `--font`（系统字体栈）与 `--font-mono`（slug / id 用等宽）。
  > 已知偏离：反模式建议避免 system-ui 作主字体。**本 change 不改全局字体**（属 `L-restyle` 范围，会波及全站 34 页）；本页只继承，记为"既有基线偏离，不在本 change 修"。
- **间距标度**（非线性，避免 4/8/12/16 机关枪）：`6 / 10 / 14 / 20 / 28`。
- **字号**：页标题 16 · 区块 13 · 正文 12.5 · 辅助 11 · 极小徽章 10.5。

## 5. 组件清单与状态

| 组件 | 状态 | 说明 |
|---|---|---|
| `Tabs`（团队/小队） | 选中/未选中 | 语义用 `role="tablist"` + `aria-selected` |
| `ListCard` | 默认/悬停/选中/我的角色徽章 | 单层卡片；选中用左 2px `--blue` 内描边（不是彩色侧条块） |
| `DetailDrawer` | 打开/关闭/加载中 | `Esc` 关闭；关闭按钮 `aria-label="关闭详情"` |
| `Section` | 折叠/展开 | 标题 + 计数；折叠按钮 `aria-expanded` |
| `FormRow` | 默认/校验错/禁用 | 每个输入都有 `<label>`（**不用 placeholder 顶替 label**） |
| `StatusChip` | active/paused/archived | 文字 + 颜色双编码 |
| `QuotaBar` | 正常/接近上限（≥80%）/超限 | 文本必须写「已用/上限」，不只靠颜色 |
| `EmptyState` | 团队空 / 小队空 / 成员空 / 资产空 | 各有引导文案 |
| `ErrorBanner` | 读失败 | `role="alert"`，可重试 |
| `InlineError` | 写失败 | 就地显示后端 `detail` 原文 |

**加载态**：首屏用一行文字「加载中…」（与既有页面一致），不用纯灰条 skeleton（反模式）。

## 6. 交互细则

1. **不可逆动作二次确认**：`归档团队`、`归档小队`、`转让 owner` 三个动作必须经过确认步骤（勾选或内联确认行），文案写明后果。归档团队额外提示「不可恢复」。
2. **禁用要给原因**：`archived` 团队的「添加成员 / 挂载资产」按钮 `disabled` 且 `title="团队已归档：只停未来指派与变更"`。
3. **错误不吞**：写失败显示后端 `detail`（如「配额超限 max_members=5」「资产已属于其他团队」「owner 必须通过转让产生」）。
4. **非成员不可见**：列表只渲染后端返回项；**不出现**「存在但你无权查看」的提示（避免探测面）。
5. **资产挂载**：`kind` 用下拉（五类），`asset_id` 数字输入；旁注「当前需手填 ID（候选选择器待后端提供）」。
6. **键盘**：Tabs 用左右方向键切换；Drawer `Esc` 关闭；表单 Enter 提交（非多行输入时）。

## 8. 无障碍检查表（本页适用项）

- [ ] 每个输入有 `<label>`（或 `aria-label`）；不用 placeholder 代替
- [ ] Tabs：`role="tablist"` / `aria-selected` / 方向键切换
- [ ] Drawer：`Esc` 关闭 + 关闭按钮有 `aria-label`
- [ ] 折叠区按钮有 `aria-expanded`
- [ ] 状态不只靠颜色：chip 有文字，配额有数字
- [ ] 错误用 `role="alert"`；成功/计数用 `role="status"`
- [ ] 焦点可见（沿用全局 `:focus-visible`）；禁用按钮有 `title` 原因
- [ ] 无 `prefers-reduced-motion` 风险（本页不加动画，只复用既有 `--fast` 过渡）

## 9. 占位符与图像策略

- **无图片、无头像上传**：成员用「首字母方块」+ `user_id` 文本；Agent/小队用 `--font-mono` 的 id 片段。
- 不使用 lorem ipsum；所有空态有中文引导。

## 10. 自检（对齐 `ui-anti-patterns` 强制禁忌）

| 禁忌 | 本页是否命中 | 处理 |
|---|---|---|
| 纯黑/纯白 | 否 | 用 `--bg-*` / `--text` 倾斜中性色 |
| 紫色渐变 / 霓虹青 | 否 | 无渐变 |
| 两个以上强调色 | 否（状态色带文字，不算装饰强调） | 见 §2 |
