## 2. 安全轮（本 change 的信任边界）

- **授权**：前端**零判断**；按钮可用性只反映后端已知角色，最终由 403/404 决定（D5）。用例断言"错误文案原样显示"，即不吞 403/404。
- **越权探测面**：非成员团队不出现在列表（后端过滤）；页面不出现"存在但无权"提示。
- **注入面**：无新增后端输入解析；前端仅拼接已编码 URL 段（`encodeURIComponent`）。
- **凭据**：页面不读取/缓存任何密钥；`leader_agent_id` 等均为公开标识。

## 3. 兼容 / 性能轮（抽查）

- **兼容**：零新增依赖（`lucide-react` / `zustand` / `requestDedup` 均既有）；窄屏 ≤900px 堆叠为 CSS-only（未在真实设备验证，记 UAT 未覆盖）。
- **性能**：列表一次拉取；详情**按需**拉取（D2），避免 团队数 × 详情 的 N+1；写后失效缓存再拉，不做全表刷新循环。
