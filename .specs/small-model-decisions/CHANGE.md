# CHANGE — small-model-decisions

> **状态**：已定稿（2026-09-22 四项澄清回答入账：A+B+C 首批全要 · 消费级基线 · 域内隔离+显式开关 · 内置基准+用户回放）
> **日期**：2026-09-22 · **来源**：用户原话三点需求
> **上游关联**：`PRODUCT-DESIGN.html` §1.4「不做语义（NLP）路由——列为远景，未实现」；`platform-evolution/ROADMAP.md` P1-12（审批语义协议对齐，同属"决策基础设施"族但互不阻塞）

## 1 · Why

- 当前路由是**标签匹配 + 最小连接数**的确定性策略（代码事实），语义路由挂"远景"牌子挂了很久；每次复杂对话全量喂超大模型，贵且慢。
- 品类信号：Jev（TypeSafe AI，2026）提出 System One 决策模型——**小模型不生成文本，只吐带校准概率的分类/选择/评分**；单决策 ~77ms、Q4_K_M 1.3GB 可本地跑、ECE 0.017（校准=概率可直接当置信度用，这是路由决策的硬需求：知道"何时该升级给大模型"）。社区复刻（Qwen3.5-2B，Apache-2.0）证明**自训门槛低**（LoRA rank 16 + 22k 样本配方）。
- 用户价值：三层——①决策便宜（路由/门禁/简单加工任务下沉）②越用越准（平台独有的对话与记忆数据微调专属决策模型）③可信（自带校准 + 自测）。

## 2 · What（范围候选 A/B/C/D，逐条过 ⑤ 门后才算承诺）

### A · 决策小模型分层层（语义路由的 System One 化）
- 新增「决策模型」抽象：类型化输入（state + question + typed options）→ 校准概率分布输出，三型 Choice/Bool/Score 对齐 Jev 语义
- 接入位 1：**调度路由**——候选 Agent 集作为选项，Choice 决策 + 置信度；低置信自动升级大模型（fallback 策略）
- 接入位 2：**对话中心语义分诊**（补上"远景"欠条）：消息 → 意图分类 → 分流到编排/直答/工具
- 接入位 3：**简单任务直接派发小模型**（建文件、单句加工类）——需先定义"简单任务白名单"，宁窄勿宽
- 模型来源：**本地（llama.cpp/LM Studio server，OpenAI 兼容口）** + **云 API** 双轨；预置推荐清单（Jev-Style 复刻、0.6-4B 级分类器、deberta 类纯分类头）
- 校准概率进审计与前端徽标（"80% 就是 80%"是这个品类卖得动的根因）

### B · 微调工厂（对话与记忆 → 专属决策模型）
- 数据源：平台对话日志 + 记忆库，**显式 opt-in 开关 + 隔离域数据边界**（默认关；导出脱敏可审计）
- 训练框架：**LLaMA-Factory 为适配目标**（消费方自装 CLI/引擎，平台只做编排调用与任务台账）；检测硬件不达标 → 功能置灰 + 明写原因（用户原话"不支持就拉倒"的 UI 语言）
- 产出登记：微调结果作为新模型版本入模型目录（带训练数据指纹/基座/配方），可回滚

### C · 微调自测
- 内置评测集（held-out + 用户样例回放）三指标：**准确率 / ECE 校准误差 / 与基线模型决策一致率**（复刻版模型卡同款口径，有业界可比性）
- 达标才允许切换生产版本（门禁在状态转换层，对齐既有纪律 §1.6.5 ①）

### D · 交互入口
- 对话框内以工具/斜杠命令触发（"推荐小模型""微调这个分类器""测一下 v3"）；模型管理面新增「决策模型」页（挂 p7 工具市场或新页，UI 设计阶段定）

### E · 环境参谋（机器自适应部署方案，2026-09-22 用户追加原话）
- 「根据你的机器配置以及机器自身推荐需要安装的玩意、小模型、推理工具，自己识别给出一个可执行方案」
- 链路：硬件画像检测（只读探测）→ 部署方案库匹配（引擎×模型×量化×步骤）→ 分层方案卡：命令可复制、脚本可下载
- **红线（用户修订原话「只给方案不执行 让用户决定是否安装」2026-09-22）**：参谋零执行——不装引擎、不下模型、不写配置，所有动作以可复制命令/可下载脚本形态交付，装不装、何时装由用户决定（原"白名单代执行"设计取消）；机器配置只画像不上传（用户确认「机器配置当然不上传」）；识别不了就诚实说，降级到云 API 档，不瞎猜配置

## 3 · 不做（边界草案）

- 不做生成型大模型的替代——小模型只出决策不出内容
- 不自带训练引擎发行（LLaMA-Factory 等由使用方安装，平台只编排）
- 不做无监督"悄悄学"：所有数据进微调必须显式开启（合规红线，参照 multica 归属 fail-closed 纪律）
- 暂不做 >26 选项的大规模分类（Jev 语义上限 26 选项，超出场景走大模型）
