# REQUIREMENT — small-model-decisions

> **change-id**: `small-model-decisions` · 2026-09-22
> 上游：`CHANGE.md`（已定稿）+ 用户补充原话：「**这种分类小模型我们是提供能力，如果用户不显性指定或者没有配置就不要用了**」（2026-09-22，本文件 AC-0 的依据）

## 1 · 用户故事

- **US1 域管理员**：作为域管理员，我想在自己的域里**显式登记并绑定**决策小模型（本地 llama.cpp/LM Studio 或云 API），以便路由决策只在我要它工作时才工作。
- **US2 调度系统**：作为调度器，我想在**已绑定决策模型的域**用一次 ~80ms 的类型化决策选出候选 Agent，以便替代粗粒度标签匹配并给每次选择附校准置信度。
- **US3 平台运维**：作为运维，我想看到每条决策的「模型版本 + 概率分布 + 是否因低置信升级大模型」，以便任何一次路由异常都可回放归因。
- **US4 终端用户**：作为用户，我想让"建个文件、对一句话做加工"这类简单任务由便宜的小模型直接完成，以便省钱提速且复杂任务不受影响。
- **US5 域 Owner（微调）**：作为域 owner，我想**显式开启**后用自己的对话与记忆数据微调专属决策模型（LLaMA-Factory 编排），以便越用越准且数据不出域。
- **US6 平台用户（自测）**：作为用户，我想对微调结果跑准确率/校准误差/基线一致率三指标，不达标就**上不了生产**，以便自动化是可信的而非玄学。
- **US7 终端用户（入口）**：作为用户，我想在对话框里用斜杠命令触发推荐/微调/评测，以便不离开对话完成全部操作。

## 2 · 验收准则（AC）

### 铁律层（用户原话入账）

- **AC-0 未配置 = 零介入**：Given 某域未登记或未绑定任何决策模型，When 该域发生任意调度/对话/派发行为，Then 系统行为与今天完全一致（走既有「标签匹配 + 最小连接数」直通路由），决策模型相关代码路径**零调用**（以审计计数=0 验证），且界面无任何自动"建议启用"的骚扰。
- **AC-0b 显式两步制**：Given 管理员已登记模型（连接可用），When 未在「域策略」里把它绑定到具体用途（路由决策 / 对话分诊 / 简单任务派发 各自独立开关），Then 该用途仍然零介入——登记≠启用。

### A · 决策小模型分层层（v1）

- **AC-A1 类型化决策契约**：Given 已绑定路由决策模型，When 调度需要选择候选（state + question + options ≤26），Then 返回选项全集的归一化概率分布与 top1，本地 Q4 单次 ≤300ms（含 HTTP 往返），超时/畸形响应即回退直通路由并记 `decision_fallback`。
- **AC-A2 置信度升级**：Given 决策 top1 概率 < 域配置阈值（默认 0.6，管理员可调），When 路由发生，Then 自动升级大模型处理并在 runtime 标注 `escalated`；阈值语义写入帮助文案（校准模型的概率≈真实置信这一前提要在 UI 说清）。
- **AC-A3 对话分诊（可选启用）**：Given 域启用分诊绑定，When 新消息到达，Then Choice 决策分流至 编排请求/直接问答/工具调用 并可在消息详情看到分类与概率；未启用则分诊路径零调用（回 AC-0）。
- **AC-A4 简单任务白名单**：Given 域启用简单任务派发，When 任务属内置白名单（建文件、单句加工等窄集），Then 小模型直接执行，输出经 schema 校验后交付；**校验失败自动重交大模型**；非白名单任务禁止派发（服务端枚举校验，不靠提示词）。
- **AC-A5 双轨与台账**：Given 本地服务不可达，When 该模型配置了云 API 备用，Then 自动切换并标 `source=cloud_api_fallback`；两轨模型均入「决策模型目录」（provider/基座/量化/最大选项数/用途绑定/健康态）。
- **AC-A6 全量审计**：每次决策落 `runtime.jsonl`：模型版本、输入摘要、概率分布、耗时、是否升级/回退——支撑 US3 回放。

### B · 微调工厂（v1，消费侧受硬件门约束）

- **AC-B1 域级显式开关**：Given 微调开关处于默认关，When 任何训练操作发起，Then 403 + 引导开启文案；开启动作仅域 owner 可做且入审计。
- **AC-B2 数据不出域**：Given 开关已开，When 构造训练集，Then 仅取**本域**对话/记忆数据，经 PII 脱敏管道，产数据集指纹（条数/来源范围/哈希）入台账；导出物可查「哪些会话被用过」。
- **AC-B3 硬件预检**：Given 发起本地微调，When 检测不满足基线（2B 级 LoRA：显存 ≥8GB 或 Apple 统一内存 ≥16GB；推理不受限：Q4 GGUF 1.3GB 级），Then 微调入口灰显并明写缺什么；**云 API 轨不受此门**。
- **AC-B4 编排不自带引擎**：Given 平台检测到本机 LLaMA-Factory CLI（PATH 或配置路径）可用，When 发起微调，Then 平台生成任务（基座/LoRA 配方/数据指纹）→ 调用 CLI 执行 → 记录状态与日志；未安装时给安装指引并**拒绝代装**。
- **AC-B5 版本登记与回滚**：微调产物注册为新模型版本（血缘：基座+配方+数据指纹），可在目录中一键切生产/回滚；切生产前先过 C 层门槛。

### C · 自测评测（v1）

- **AC-C1 三指标报告**：Given 新微调版本，When 跑自测，Then 输出 准确率 / ECE / 与前一生产版本决策一致率；数据集 = 内置公开基准子集（GLUE/BoolQ/AG News 同款口径，与 Jev 模型卡指标可比）+ 用户勾选的回放样例。
- **AC-C2 门禁在状态转换层**：Given 指标未达域配置门槛（默认 accuracy ≥80% 且 ECE ≤0.05，参考 Jev 复刻版 82.3%/0.017 量级定标），When 试图设为生产版本，Then **服务端拒绝**（不是提示词约定）；门槛数值本身是域策略可审计项。
- **AC-C3 基线可比**：未微调的基座同款任务得分并列展示，让「微调赚了多少」一眼可见。

### D · 对话入口（v1 薄版）

- **AC-D1** 对话框命令 `/决策模型 推荐|登记|微调|评测|状态`（名可再定），触发即走对应流程，`/help` 可发现；命令仅对**已开对应能力**的域显示效果（呼应 AC-0）。

## 3 · 范围切分

- **v1**：AC-0/0b、A 全、B 全（本地轨优先，云训练不做）、C 全、D 薄版。
- **v2**：云训练任务兜底；>26 选项的大规模分类；外接 lm-eval 等评测框架；模型推荐"适合干什么"元数据富集与效果榜；微调配方模板库（LoRA rank/学习率预设）。
- **out（永远不做，除非重新立项）**：未显式绑定的任何自动启用或"猜你要用"；把生成质量微调混入决策模型目录；平台内置分发训练引擎；用微调模型替代大模型做复杂任务。

## 4 · 非功能需求

- **性能**：决策 P95 ≤300ms（本地 2B Q4）；微调预检 ≤5s；决策失败不得阻塞主调度（回退时限 1 个 tick）。
- **安全与隐私**：微调数据域内隔离 + 显式开关 + 脱敏 + 台账（B 全章的前提）；决策模型端点凭据不进 wire 日志（对齐既有纪律）；`/决策模型` 命令受域 RBAC。
- **可观测**：概率分布全量入审计；`decision_fallback/escalated` 计数进监控仪表盘（新指标组）。
- **兼容**：推理接口 OpenAI-compatible（llama.cpp/LM Studio/主流云 API 三兼容）；LLaMA-Factory 版本窗口在 DESIGN 锁定（先测 0.9x，版本漂移用能力探测不用版本号硬判——multica 纪律）。
- **可访问性/文案**：灰显原因、门槛含义、校准语义都写成用户可读文案（不藏 hover）。
- 无多副本要求（现状单进程纪律不变）。
